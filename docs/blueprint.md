# **App Name**: Medagram

## Core Features:

- Patient Chat: Telegram-like interface dedicated to each patient for streamlined communications.
- File Sharing: Secure file sharing for medical documents and images (PDF, image, audio, DICOM).
- Patient Info: Persistent drawer for quick access to patient information (age, diagnosis, meds).
- Quick Replies: Suggested templated messages that the user can choose and then optionally customize for rapid response

## Style Guidelines:

- Calm blue (#5DADE2) to promote trust and serenity.
- Light grey (#F0F4F8), creating a clean and professional backdrop.
- Muted green (#A3E4D7) for actionable items and confirmations.
- 'PT Sans' (humanist sans-serif) for optimal readability and a touch of warmth.
- Use clear, recognizable icons relevant to hospital environment (e.g., stethoscope, file folder).
- Clean, minimal interface with rounded buttons to make it appear friendly. Message reply input bar sticks to the bottom. Key action buttons such as attaching file and 'Quick Replies' float above the reply bar.
- Subtle transitions on element appearance and quick button presses (on press transitions, material design transitions).
